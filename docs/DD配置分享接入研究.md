# 网易 DD 配置分享接入研究

核验日期：2026-10-26。目标：露露缇娅 NDui 国服时光服完整配置，分享码 297986。

## 已确认

- 官方只读搜索、详情接口可读取分享元数据。目标分享 ID 为 `da34464e69804c11bfd87fd52fc691d3`，时光服分支为 2。公开详情中的配置下载地址为空，不能以公开免费标记推断已获得下载权限。
- 官方部署网页的“安装分享”处理逻辑调用客户端唤起函数，将分享 ID、客户端分支传给 DD 客户端，不在浏览器直接下载安装。
- 官方部署资源中插件登录流程涉及 `/login/dslogin` 和 `x-w163-token`；原生桥接还暴露 `nepHttpGetSignedUrl`、`nepHttpPostSignedUrl`。部分旧签名调用在当前资源中已被注释，不能据此断言当前客户端每个请求都经过该调用。
- 本次不带用户凭据的只读请求：`/login/dslogin?ef=0&uf=0&ts=0&ab=0` 返回 HTTP 200，业务码 **409，消息“签名无效”**。这是请求签名失败，不能诊断为账号无权限或密码错误。
- 去掉上述固定参数后，同一登录端点返回 HTTP 422，不能靠删除参数解决认证。
- 匿名请求 `/share/version/detail` 返回业务码 412“用户登陆失败”。此接口不是匿名下载入口。
- 携带 Origin `https://dd.163.com` 的响应允许该来源以及 credentials；分享接口 OPTIONS 响应列出允许请求头 `x-w163-token`、`x-timestamp`。房间网页的 CSP connect-src 也允许 163.com 子域。尚不能证明 WebKit 的全部网络/会话行为正常，但没有证据将当前失败简单归因于来源被全面禁止。
- 用户实际完成过官方 DD 网页登录；先前直接带 Cookie 读取详情仍无下载地址，补充插件登录请求后 WebKit 报脚本异常。未获取该次请求的具体业务码，不能把匿名 409 直接当作该次已登录请求的返回值。

## 当前判断与限制

单纯网页登录 Cookie 或空签名参数不能证明已取得插件服务会话。现有公开资料不足以确认第三方原生应用可获得所需签名/登录凭据；搜索未找到官方公开的第三方接入文档，这不等于官方一定没有合作接口。

当前应用只提供分享查询和实验性登录读取，不提供配置下载安装。后续需要官方支持的登录/签名 SDK、第三方授权方式或公开下载接口之一，并实际验证返回的归档结构。不会猜测 CDN 下载地址、提取其他客户端私有凭据或伪造官方客户端身份。

取得归档后仍需实现独立的 WTF/字体/材质备份恢复、安装范围预览、目标账号与角色映射、同卷事务与回滚。现有 AddOns 备份不能充当完整配置备份。

## 官方接入需确认的问题

1. 是否支持第三方原生 macOS 插件管理器访问公开免费配置分享？
2. 应使用哪种授权流程取得插件服务会话？是否提供 SDK、应用注册和签名文档？
3. 是否允许下载分享内插件、WTF、字体和材质，相关下载/归档协议及使用限制是什么？

没有向网易或作者发送消息、创建账号、购买或订阅分享；没有修改游戏文件。
