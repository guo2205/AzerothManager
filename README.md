# 艾泽拉斯 · 插件管家 0.12

原生 SwiftUI 中文 macOS 魔兽世界插件管理器，支持国服时光服和正式服，使用网易 DD 检测插件版本和下载更新；普通插件更新无需账号或 API Key。配置分享的下载权限另需验证。

## 使用

1. 解压 `AzerothManager-v0.12.app.zip`，启动应用，选择游戏目录或现有的 `Interface/AddOns`。
2. 核对客户端用途。国服时光服匹配 DD 泰坦重铸分支，正式服匹配 DD 正式服分支。
3. 插件库按 DD 项目 ID 将整包合并为一行，展开可查看各子目录及独立 TOC 版本；没有可靠来源的目录单独显示。搜索包名、子目录或作者会显示整个包。插件库在启动、重新扫描或安装后自动检查。可更新插件置顶，未识别/冲突/检查失败居中，已是最新置底；同组保留原有顺序。搜索名称、文件夹、作者时仍保留这个优先级。
4. 点击「更新全部（N 包）」会更新全部已检查且允许更新的包，不受搜索过滤影响；同一包只下载、安装一次，按顺序执行，失败单独记录并继续后面的包。可取消未完成的网络任务和后续更新；已开始的文件事务会完成或回滚。每个包安装前各自创建完整备份，成功的包不因其他包失败而撤销。顶部结果保留成功、失败、未执行数量和失败原因。
5. 列表分别显示「本地 TOC 版本」和「DD 整包版本」（已装包、最新包及所属包名）。子模块 TOC 版本独立，不用整包或依赖插件的版本替代；多目录包显示「更新整包」，可在选中后的详情中核对目录范围。点击「更新」或「更新整包」直接下载最新匹配的正式包、校验、备份整个 AddOns 并安装。包内多个文件夹会一起更新。请先退出游戏。
6. 「在线插件」默认加载网易 DD 周热门，支持月热门、总下载量、搜索和翻页。排行榜来自 DD 官方下载量排序，每页 20 个，显示对应下载次数。点击「热门插件」可清空搜索并返回排行。新插件暂通过 DD 官方页面安装，装好后可在插件库更新。
7. 支持手动导入 ZIP、卸载、备份和恢复；修改前自动备份。支持整包批量更新；没有依赖自动安装或无人值守定时更新。

## 桃桃 Core 插件版

「在线插件」顶部提供独立的 **桃桃 Core · 插件版** 入口。点击「检查最新版本」读取[作者官方项目 26150](https://www.wclbox.com/games/1/PluginItem/26150)的当前正式发布，然后「下载并预览安装」，核对后备份整个 AddOns 并安装。当前公开发布无需登录；服务不再提供公开访问权限时会中止并提示，不绕过权限。仅启用已核实的时光服分支，正式服入口禁用。

核对日期 2026-10-31：发布包 `TaotaoCore_0.3.6`，TOC 版本 `0.3.6`。界面分别显示最新发布名与本地 TOC，不把二者的字符串差异当作版本先后，也不宣称后台自动更新；重新点击检查可获取新发布，按同一流程升级或重新安装。

安装只整体替换 `TaotaoCore`，保留 WTF、原职业 WA 和其它插件。作者说明要求在游戏内停用 `VF_Core`、`VF_Interface`、`VF_HekiliFollower` 三个旧核心组件，原 WA 职业策略继续使用；应用不会自动删除它们，也不附带职业策略。预览前后核对官方发布清单与本地 SHA-256 指纹，文件变化会要求重新预览。备份可在「备份与恢复」中恢复。

## 新手盒子配置分享

「配置分享」现支持新手盒子六位分享码，默认露露 NDui 时光服配置 **867253**（与网易 DD 的分享码不同）。在应用内扫码完成新手盒子官方微信授权后，读取有权限访问的分享、对应客户端的正式插件文件和资源清单。临时访问凭据仅在内存中保留；不保存密码、Cookie 或刷新凭据，退出应用后需要重新登录。本地账号、服务器、角色和 SavedVariables 不上传。

1. 先运行过游戏并退出，让应用能识别 `WTF/Account` 下的本地角色。选择来源角色和需要安装到的本地角色，可多选。
2. 分别选择插件、账号公共配置、角色配置、材质、字体；字体默认关闭。共用同一目录的多个插件发布包必须明确选择目录来源后才能继续。
3. 点击「下载并预览」，完成下载、安全解压、清单检查和角色索引映射；预览期间不写入游戏。确认文件数量、覆盖范围与目标目录后，再点击安装。
4. 安装前完整备份 `Interface`、`WTF`、`Fonts`，按同卷暂存和重命名提交；异常尝试回滚。中断记录尚未恢复时禁止继续修改插件，可在本页点击「恢复中断安装」。完整配置备份可单独恢复，恢复前也会备份当前状态。

**账号公共配置可能覆盖个人 WA、键位、宏，并影响所选账号的其他角色。** 本版映射明确的角色复合索引以及 NDui 的服务器→角色表；保留来源配置名与嵌入代码，不执行 Lua，也不做个人 WA 的增量合并。游戏内兼容性仍需进入游戏检查。

当前支持官方清单中的「跟随最新版」已知插件。锁定/忽略策略、未知插件归档、没有访问权限的内容会明确拒绝或标为不可选，不会猜测文件地址。NDui 样例整包已在一次性目录验证，不能据此保证所有作者的配置布局均兼容。接口是当前官方客户端使用的服务，未来可能变化；没有绕过购买或账号权限。

下载仅使用固定 HTTPS 官方资源域名，拒绝重定向；ZIP 校验 CRC、路径、类型、大小和目录清单。字体分片核对长度并重复核对索引；服务的 FastSample 字段不等于已验证的整文件密码学摘要。安装预览和备份另有本地 SHA-256 内容指纹。网易 DD 配置下载仍未接通，历史研究见[接入研究](docs/DD配置分享接入研究.md)。

## DD 匹配与校验

使用官方 `POST /addon/scan?ef=0&uf=0&ts=0&ab=0`，不依赖本地 `addon_strategy.txt`。仅发送插件文件夹/TOC 文件名、TOC 的 MD5、客户端分支和正式版策略，不上传 Lua 源码、绝对路径、WTF 或账号数据。时光服使用分支 2，正式服使用 10001。

DD 的 `local_version` / `latest_version.version` 是整个发布包的版本，不是每个子目录的版本。例如子模块 TOC 可以是 1.6，而所属包版本是 3.93；界面分别显示，子模块不会被标成“最新 TOC 版本 3.93”。接口没有提供新版子目录的独立 TOC 版本时，不猜测该值。

按 DD 返回的项目/文件 ID 和包级完整匹配判断，避免把子模块 TOC 版本误当作整包版本。完整、唯一且无冲突的匹配才提供自动更新；未识别、部分匹配、目录重叠、缺少下载地址时明确提示。DD 不保证覆盖所有插件，不对任意版本字符串强行排序。

批次会拒绝目录交叠和同包文件 ID 不一致的任务。每包只核对自身旧目录及已声明目标目录的内容指纹，避免前面包更新后让后面的包误报变化；新出现的同名目录仍会中止覆盖。更新前重新扫描，确认最新文件 ID 未变化并刷新下载地址。只从 HTTPS `uires.w.163.com/file/` 下载普通 ZIP，最多 256 MiB；检查声明大小、ZIP CRC、路径和解压体积。解压后再向 DD 核对 TOC 对应文件 ID、完整匹配和目录集合。不执行插件代码。检查后本地文件变化或出现新的同名目录会中止安装，需重新检查。

DD 没有提供整个 ZIP 的密码学摘要，上述校验不能等同于整包签名或整包密码学摘要校验；首次「已是最新 · DD（TOC）」也不证明所有 Lua 文件都未修改。本应用安装记录另保存 SHA-256 内容指纹，后续可检测本地修改。

## 备份与记录

普通插件备份位于 `~/Library/Application Support/AzerothManager/Backups`，包含完整 AddOns 和来源记录，不包含 WTF/SavedVariables。恢复前会再备份当前目录；恢复会整体替换 AddOns，备份暂不自动清理。操作期间请停止其他管理器与外部文件修改。

完整配置备份另存于 `~/Library/Application Support/AzerothManager/ConfigurationBackups`，包含 Interface、WTF、Fonts；它与普通插件备份相互独立，请在配置分享页恢复。

安装记录 `.azeroth-dd.json` 保存项目/文件 ID、版本、客户端、目录和本地内容指纹。手动覆盖、卸载会清理冲突记录，备份恢复包含记录。不会主动清除新版移除的旧目录。

ZIP 支持 Stored/Deflate；拒绝路径穿越、绝对路径、符号链接、重复路径、大小写/Unicode 冲突、加密、ZIP64、CRC 不符和超限归档。安装按文件夹整体替换，使用同卷暂存与重命名提交，异常尝试回滚。

## 编译与预览

需要 macOS 14+、Xcode 15+、Swift 5.9+。打开 `AzerothManager.xcodeproj`，选择 AzerothManager → My Mac 后运行。命令行验证：

```sh
swift test
scripts/run-latest.sh
```

预览脚本构建 Release、关闭旧版进程、替换 `outputs/AzerothManager.app`，清理项目旧应用和旧发行 ZIP，仅打开最新版；保留游戏数据、用户设置和备份。Git 提交标题、正文及新增标签说明统一使用中文。

默认测试不访问真实游戏目录；专项真实下载测试需显式启用，在随机临时目录用固定公开旧版 ZIP 验证单目录和多目录更新：

```sh
AZEROTH_DD_LIVE_TEST=1 swift test --filter DDSourceTests/testLiveDDDownloadAndInstallOnTemporaryCopy
```

应用使用本机临时签名，未做 Developer ID 发行签名或 Apple 公证。通用二进制包含 Apple Silicon / Intel，Intel 未在实机验证。未验证断电、磁盘耗尽、外部并发写入的所有组合和真实游戏内兼容性。详细记录见 `VALIDATION.md`。

随附 `Demo/World of Warcraft` 与 `Demo/HelloAzeroth-2.0.zip` 可试验导入、卸载、备份和恢复；演示插件应显示「DD 未精确匹配」，演示接口号不应安装到真实客户端。
